6  Closing Remarks

At this stage, we have built the SVM idea in layers:

  1. start with a separating boundary,
  2. choose the boundary with the largest margin,
  3. allow margin violations through a soft margin,
  4. create nonlinear boundaries through feature expansions and kernels.

The final question is no longer how does the SVM work? It is:

when is an SVM a sensible modelling choice?

This is a practical question. SVMs can be powerful classifiers, but they are not automatic winners. They work best when the geometry of the problem matches the way the model thinks about classification: through boundaries, margins, support vectors, and similarity.

6.1 Where SVMs Work Well

An SVM is usually worth considering when the main goal is accurate classification and the boundary between classes is important. The model does not begin by estimating probabilities or modelling class distributions. It begins by asking where a good separating boundary should be placed.

This is useful in several common settings:

  • the classes are reasonably separable, at least after allowing a soft margin
  • the decision boundary is more important than coefficient interpretation
  • nonlinear structure may exist, but manageable

An SVM returns a classification rule and a decision score. That score is related to which side of the boundary an observation lies on, but it is not probability. If probabilities are central to the analysis, then a different model may be more natural.

SVMs are natural when classification geometry matters more than probability modelling.

6.2 An SVM Modelling Workflow

A useful way to approach SVMs is to avoid starting with the most flexible model. Flexibility is valuable only when the data require it. Remember, statistical modelling is about parsimony.

A reasonable SVM workflow is:

  1. Perform EDA on the predictors using the training data.
  2. Fit a linear SVM and tune the cost parameter.
  3. If the linear boundary is too restrictive, try a nonlinear kernel.
  4. Tune the relevant parameters using cross-validation.

This workflow follows the building blocks we have used whilst covering the topic. Is this simple case good enough? If not, make it a little more complex.

NoteA small warning about scaling

SVMs are sensitive to the scale of the predictors because margins and kernels are built from norms or dot products. If predictors exist on drastically different scales, the larger-scale predictor can dominate the geometry of the classifier.

If you do scale the predictors with scale = TRUE in the svm function; then you need to be careful about the result. Methods such as predict and plot are safe with respect to scaling, but the coefficient and rho return objects are in the scaled predictor space.

6.3 Limitations

The main practical limitations are:

  • Scaling matters. Predictors usually require standardisation before fitting.
  • Tuning matters. The cost parameter controls the soft margin, and nonlinear kernels introduce additional parameters such as gamma or polynomial degree.
  • Probabilities are not primary. SVM scores can be calibrated, but probability estimation is not the model’s starting point.
  • Interpretability can be limited. A linear SVM has some mild interpretability through its boundary; but, kernel SVMs are even harder to interpret directly.
  • Large training sets can be difficult. Kernel SVMs can become computationally expensive as the number of observations grows.
  • Categorical and missing predictors need care. Predictors usually need to be encoded and cleaned before fitting the model.

6.4 Applications

SVMs have been used successfully in many applied settings. The exact list is less important than the pattern. They are useful when classification is important, the predictor set is rich, and a good boundary can be learned from the data.

Typical examples include:

  • text classification, where documents can be represented by many sparse word or phrase features
  • image or signal classification, where the feature representation may be high-dimensional
  • bioinformatics, where the number of predictors can be large relative to the number of observations

These examples also show why SVMs became popular. They can perform well in high-dimensional feature spaces, and kernels give a principled way to add nonlinear flexibility.

6.5 Extensions Beyond Our Scope

The SVM framework has several extensions.

  • Support vector regression adapts the margin idea to regression problems.
  • One-class SVMs are used for novelty or outlier detection.
  • Multiclass SVMs combine binary SVMs to handle more than two classes.
  • Structured or ranking variants adapt the margin idea to more complex prediction tasks.
